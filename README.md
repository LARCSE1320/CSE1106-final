# CSE1106-final
## This project is our final CSE 1106 project for section 010. This project is the Smart Classroom Comfort Monitor.
## This project will be using c code along with raspberry pi4s to prompt the user to enter temperature readings in fahrenheit, determine if the temp is within acceptable range(68F-76F), print out a status report at the end of the code that contains warnings and the average temp read, and have a light turn on when a temp or temps are outside the acceptable range.
## We learned how to integrate code and raspberry pis together to create a program with more moving parts than just a regular c program that only uses the compiler.
